On this page, you will learn to:

  • Convert equations between rectangular and cylindrical coordinate systems.
  • Set up and evaluate triple integrals using cylindrical coordinates.

The cylindrical coordinate system is an extension of the polar coordinate system from 2D to 3D. Recall that the polar coordinate system defines \( (x,y) \) points as \( (r, \theta ) \) where \(r\) is the radial distance from the origin and \(\theta\) is the rotation about the origin from the positive \(x\)-axis. In the cylindrical coordinate system, we express the point \((x,y,z)\) as \((r,\theta,z)\). So the \(x\) and \(y\) position of the point is defined in polar and the height is still \(z\).

The cylindrical coordinate variables can be defined as follows.

  1. The variable \(r\) represents the 2D radial distance within the \(xy\)-plane from the origin to the point's projected location onto the \(xy\)-plane.
  2. The variable \(\theta\) represents the angle of rotation about the \(z\)-axis where we often assume \(0 \le \theta \lt 2\pi\). The variable \(\theta\) works exactly the same way in cylindrical as it does in polar.
  3. The variable \(z\) represents the vertical height of the point above or below the \(xy\)-plane, just like it does in the rectangular coordinate system.

Note that it is possible to reorient the cylindrical system about a different axis. The standard orientation uses the coordinates \((r,\theta,z)\) where the \(z\)-axis is the pole with \(r\) and \(\theta\) measured within the \(xy\)-plane. This would correspond to a cylinder centered along the \(z\)-axis. However, we could just as easily reorient the system to use the coordinates \((r,\theta,y)\) where the \(y\)-axis is the pole with \(r\) and \(\theta\) measured within the \(xz\)-plane. This would correspond to a cylinder centered along the \(y\)-axis. A similar orientation would involve \((r,\theta,x)\), which would correspond to a cylinder centered along the \(x\)-axis.

Converting Equations

There are four equations that we may need in order to convert equations between the rectangular and cylinderical coordinate systems. The first equation comes from the equation of a circle with radius \(r\) centered at the origin while the other equations are the result of applying some right triangle trigonometry.

We can convert between rectangular coordinates \((x,y,z)\) and cylindrical coordinates \((r, \theta, z)\) using the equations below.
\[x^2 + y^2 = r^2\]
\[x = r \cos(\theta)\]
\[y = r \sin(\theta)\]
\[\tan(\theta) = \frac{y}{x}\]

Triple Integrals

Given a continuous function \(f(x,y,z)\) through a solid \(D\) whose projection onto the \(xy\)-plane is a single region that can be expressed using polar coordinates, the triple integral in cylindrical coordinates of \(f\) over \(D\) can be computed using the following integral where \(D\) can be described by \(g_1(r,\theta) \le z \le g_2(r,\theta)\), \(h_1(\theta) \le r \le h_2(\theta)\), and \(\alpha \le \theta \le \beta\) for continuous functions \(g_1\), \(g_2\), \(h_1\), and \(h_2\).

\[\underset{D}{\mathop \iiint} \, f(x,y,z) \, dV = \int_{\alpha}^{\beta}\int_{h_1(\theta)}^{h_2(\theta)}\int_{g_1(r,\theta)}^{g_2(r,\theta)} \, f(r,\theta,z) \, r \, dz \, dr \, d\theta\]

The integrand will always contain an extra \(r\) expression as part of the conversion of \(dV\) from rectangular to cylindrical (polar). We will typically assume that \(r \ge 0\) and \(0 \le \theta \lt 2\pi\). While it is possible to change the order of integration, that would often require changing how the bounds are determined and that is not always easy. So, you will normally use the \(dz \, dr \, d\theta\) order of integration.
