On this page, you will learn to:

  • Determine the derivative of a function using the Chain Rule.

Back in Calc 1, you learned about the chain rule, which said the derivative of a function \(y = f(u)\) where \(u = g(x)\) would be \(y' = f'(u) \cdot u' = f'(g(x)) \cdot g'(x)\). Using the \(\frac{dy}{dx}\) notation, we could express this as follows.

\[\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}\]

Now, we want to consider the chain rule for multiple variables.

Let's consider a function with two variables that share one independent variable, \(z = f(x,y)\) where \(x = g(t)\) and \(y = h(t)\) and \(t\) is a Real variable. The derivative of \(f\) with respect to \(t\) can be determined using the formula below.

\[\frac{df}{dt} = \frac{\partial f}{\partial x} \cdot \frac{dx}{dt} + \frac{\partial f}{\partial y} \cdot \frac{dy}{dt}\]

Note that we must determine the partial derivatives of \(f\) with respect to \(x\) and \(y\) while also determining the regular derivatives of \(x\) and \(y\) with respect to \(t\).

Let's consider a function with two variables that share two independent variables, \(z = f(x,y)\) where \(x = g(s,t)\) and \(y = h(s,t)\) and both \(s\) and \(t\) are Real variables. We must determine the derivatives separately for each independent variable.

The derivative of \(f\) with respect to \(s\) can be determined using the formula below.

\[\frac{\partial f}{\partial s} = \frac{\partial f}{\partial x} \cdot \frac{\partial x}{\partial s} + \frac{\partial f}{\partial y} \cdot \frac{\partial y}{\partial s}\]

The derivative of \(f\) with respect to \(t\) can be determined using the formula below.

\[\frac{\partial f}{\partial t} = \frac{\partial f}{\partial x} \cdot \frac{\partial x}{\partial t} + \frac{\partial f}{\partial y} \cdot \frac{\partial y}{\partial t}\]

Note that we must determine the partial derivatives of \(f\) with respect to \(x\) and \(y\) while also determining the partial derivatives of \(x\) and \(y\) with respect to \(s\) and \(t\).

Implicit Differentiation

We often work with expressions that define \(f\) explicitly as a function of \(x\) and \(y\), which we express as \(z = f(x,y)\). But just like we did in Calc 1, we can also work with functions defined implicitly.

If we are given an equation \(F(x,y) = 0\) that defines \(y\) implicitly as a function of \(x\), then the differentiation process can be simplified to the following formula, where \(F_x\) and \(F_y\) are the partial derivatives of \(F\).

\[\frac{dy}{dx} = -\frac{F_x}{F_y}\]

We can use a similar process for functions with more variables. Given an equation \(F(x,y,z) = 0\) that defines \(z\) implicitly as a function of \(x\) and \(y\), we can determine the derivatives of \(z\) with respect to \(x\) and \(y\) using the formulas below, where \(F_x\), \(F_y\), and \(F_z\) are the partial derivatives of \(F\).

\[\frac{dz}{dx} = -\frac{F_x}{F_z}\] \[\frac{dz}{dy} = -\frac{F_y}{F_z}\]
